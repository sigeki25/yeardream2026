soft voting(모든 모델은 공평하다)
결과 A = (80+30+10)/3 = 40
결과 B = (20+70+90)/3 = 60


weighted Average(공부 잘하는 애의 의견을 좀 더 듣자)
결과 A = (80*0.6)+(30*0.3)+(10*0.1) = 58
결과 B = (20*0.6)+(70*0.3)+(90*0.1) = 42

Stacking
메타모델이 다른 모델들의 결과를 조합해서 최종 결과를 낸다.
기본모델 - A, B, C
메타모델 - A, B, C 의 경향성을 학습
최종 결과 : 메타모델이 기본 모델들의 내용을 받아서 경향성을 반영해 최종결과 반환
